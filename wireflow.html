Regras de negócio

R01 Detalhe lateral é overlay — não navega para nova rota. ESC fecha.
R02 SLA badge: verde (no prazo), amarelo (próximo), vermelho (atrasado).
R03 Busca dispara preview após 2 chars; debounce 250ms.
R04 Composer multi-canal: tab ativa define como mensagem é enviada.
R05 Transferência de fila pede confirmação + opção de notificar atendentes.
R06 Skeleton aparece até 1s. Se demorar mais, mostrar progress bar.
R07 Empty state inclui CTA "Criar atendimento manualmente".
R08 Tabela tem scroll horizontal em telas < 1366px; coluna Ações sticky.
